# 🌐 Web Technologies 1 (Frontend) Notes — Weeks 1 to 10

Personal lecture notes for a 10-week Web Technologies 1 (Frontend) course. Written in LaTeX, compiled to PDF, and organized by week. Made for myself, shared in case they help someone else.

## 👤 Author

**Dossymzhan Sansyzbay** — student at Astana IT University.

## 📚 Topics

| Week | Topic |
|------|-------|
| 1  | Introduction to Web Technologies: Internet & WWW basics, structure of a web page, creating a basic HTML document |
| 2  | HTML Advanced: forms, inputs, buttons, tables, semantic tags, div & span |
| 3  | CSS Fundamentals: selectors & priority, colors, fonts, spacing, alignment, classes & IDs |
| 4  | CSS Layouts: Flexbox, Grid basics, positioning systems (static, relative, absolute, fixed), float & clear, centering techniques |
| 5  | Bootstrap: responsive design, grid layout system, containers, typography, buttons, utility classes |
| 6  | JavaScript Basics: variables, operators, random number generation, conditionals, logical operations, equality checks |
| 7  | JavaScript Programming: arrays, loops, functions, DOM manipulation basics |
| 8  | Advanced JavaScript: events, DOM manipulation in depth, form validation |
| 9  | jQuery Introduction: syntax, selectors, DOM traversal, event handling, simple effects & animations |
| 10 | Final Project: building an interactive responsive website (HTML, CSS, Bootstrap, JS, jQuery) and project defense |

## 🛠️ Practice

Practice/lab sessions follow the official course plan (basic HTML pages, forms & tables, CSS styling, Flexbox/Grid layouts, Bootstrap components, JS logic and DOM manipulation, jQuery, and a final interactive responsive website project). Notes for each week focus on the lecture topic; practice-session exercises are summarized where relevant.
